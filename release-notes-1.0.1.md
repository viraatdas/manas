## An installer that says what to do, and a clearer question about analytics

- Opening the download now shows a proper installer window — Manas on the left, your Applications folder on the right, and an arrow between them — instead of a bare folder with two icons in it.
- The question about sharing anonymous usage is no longer a system alert with the whole privacy story crammed into one sentence. It now lists what Manas sends and what it never sends as two separate lists, so you can read both at a glance and decide. Nothing about what is collected has changed — only how clearly it is stated.
