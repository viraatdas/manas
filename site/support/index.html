Help with Manas.

Most sync issues are temporary. These quick checks fix the common ones; if they don’t, send a note and include what you expected to happen.

Sign-in codes

Check that your number includes the correct country code and wait a minute before requesting another code. If a code expires, request a fresh one. Never send a one-time code to support.

Todos aren’t syncing

  • Confirm both devices are signed in with the same phone number.
  • Keep Manas open briefly so the next sync can finish.
  • Check that the device has an internet connection.
  • If the problem continues, sign out and sign back in.

Delete your account

In the iPhone app, open the More menu in the top-right corner, choose Delete account, and confirm. This permanently removes your synced todos and authentication record.

Contact support

Email viraat.laldas@gmail.com. Please include your Manas version, device model, and a short description of the problem. Don’t include passwords or one-time codes.
